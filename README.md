# Bike Buyers Interactive Excel Dashboard

## Project Overview
This project is an interactive Excel dashboard built using Pivot Tables, Pivot Charts, and Slicers to analyze bike purchasing behavior.

## Tools Used
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Slicers

## Key Insights
- Working-age customers buy the most bikes.
- Medium-income groups show higher purchase rates.
- Short-distance commuters prefer bikes.
- Professionals and skilled workers are key buyers.

## Dashboard Features
- Interactive slicers for filtering
- Dynamic charts and KPIs
- Clean and user-friendly layout
